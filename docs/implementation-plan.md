# План реализации

План подготовлен отдельным агентом GPT-6 Astra по прямому поручению пользователя; затем уточнён при реализации.

1. FastAPI + SQLite, мобильная веб-страница без сборки фронтенда.
2. CRUD учеников, добавление и история оплат, должники месяца.
3. Decimal на входе и целые сотые доли в БД; календарные границы, переплата без переноса.
4. Список должников и форма рядом на десктопе, одна колонка на телефоне. Кнопка ученика лишь заполняет форму.
5. Раздельные состояния ошибок, пустой базы и отсутствия задолженности. Сохранение истории: удаление ученика с платежами возвращает 409.
6. Проверки API, ручной сценарий в браузере, запуск по README, сохранность данных после перезапуска.
7. Инструкция и честный отчёт о применении AI.

Отличия от первоначального предложения: добавлен раздел управления учениками; изменение ученика — PUT с полной моделью; будущие корректные даты разрешены и описаны, поскольку запрета в требованиях нет. Авторизация, платёжные провайдеры, Docker и бот не добавлялись.
