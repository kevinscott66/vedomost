# Ведомость — учёт оплат учебного центра

Тестовый проект: API и мобильный интерфейс для учеников, платежей и задолженности за месяц. В интерфейсе можно управлять учениками, записывать оплаты и просматривать историю. Расчёт использует Decimal и целые сотые доли в SQLite; история платежей защищена от удаления вместе с учеником.

Python · FastAPI · SQLite · HTML/CSS/JavaScript. Разработка с помощью AI, включая отдельный план Astra и автоматические проверки. Проект демонстрационный: без реальных денег, авторизации и коммерческих показателей.
