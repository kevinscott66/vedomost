# Использование AI

Реализация выполнена в Codex с AI: приложение, тесты, стили и документация сгенерированы и доработаны агентом по требованиям пользователя. Отдельный агент GPT-6 Astra подготовил план API, расчёта долга, интерфейса и проверок. Запросы с явными границами задачи — один сервер, Decimal, календарный месяц, адаптивная форма без лишней инфраструктуры — дали наиболее полезный результат. UI UX Pro Max использовался как справочник по плотности данных, минимализму и доступности; неподходящие маркетинговые шаблоны были отброшены. При доработке генератора демоданных AI пропустил импорт sqlite3: запуск и Ruff обнаружили NameError, импорт исправлен, после чего команда проверена в отдельном окружении только с рабочими зависимостями. Расчёты проверены 20 API-тестами, формы и мобильная компоновка — в браузере. Пользователь задавал требования, направление оформления и условия публикации; самостоятельное ручное написание кода пользователем не заявляется.

Это описание относится к фактической работе, а не к коммерческому опыту. Время с момента начала разработки фиксируется отдельно в личном журнале; машинное ожидание не выдаётся за время ручного программирования.
