# Использование AI

Работа выполнена в Codex: AI-агент сгенерировал приложение, тесты, стили и документацию по требованиям пользователя; пользователь задавал требования, визуальное направление и условия публикации.
GPT-6 Astra подготовил план API, расчёта долга, интерфейса и проверок, а выбранный макет Higgsfield / GPT Image 2 стал визуальной основой интерфейса.
В промптах к реализации задавались ограничения: один сервер, расчёты через Decimal, календарный месяц и адаптивная форма без лишней инфраструктуры.
GPT-6 Luna использовался для ограниченных правок и независимого просмотра отдельных частей проекта.
При проверке локализации в браузере обнаружилась потеря `{id}` в примерах API.
Подстановка `{id}` исправлена, для неё добавлена регрессионная проверка.
В браузере также не отображались узбекские названия месяцев: интерфейс полагался на данные CLDR браузера; проблему исправили явным списком узбекских названий месяцев и Node.js-проверками.
Проверки включали автоматические тесты и сценарии в браузере; подробные результаты приведены в [журнале проверок](verification.md).
