# Архитектура и дизайн

FastAPI обслуживает JSON API и статические HTML/CSS/JS с одного origin. SQLite создаётся в lifespan приложения; запросы параметризованы, внешние ключи включены для каждого соединения. Запись выполняется в транзакции. Денежные расчёты проходят на сервере через Decimal и целые сотые доли. Клиент только отображает результаты API.

Таблицы: students(id, name, phone, group_name, monthly_fee_cents); payments(id, student_id, amount_cents, paid_on). Связь payments.student_id → students.id с ON DELETE RESTRICT. Индекс payments(student_id, paid_on). Список должников — LEFT JOIN платежей в полуоткрытом интервале [первое число месяца, первое число следующего месяца), GROUP BY ученику, HAVING сумма < тариф.

Веб-клиент использует нативные формы и dialog. Данные API вставляются через textContent, не через HTML. Устаревший ответ при смене месяца отбрасывается по номеру запроса. Загрузка не смешивается с отсутствием долга. Интерфейс не использует внешние шрифты, аналитику и CDN.

## Интерфейс и темы

Визуальный источник — выбранный пользователем тёмный макет Higgsfield / GPT Image2: [reference](../design/modern-dark.png), [prompt](../design/higgsfield-modern-dark.txt), [provenance](../design/provenance.json). Первоначальный светлый и бумажный варианты отклонены и в публичную версию не входят.

Графитовая рабочая область, мятные суммы и кнопка, компактная боковая навигация, таблица слева и форма справа на широком экране. Manrope размещён локально с латинским и кириллическим наборами; иконки Lucide также локальные. Никаких внешних шрифтов/CDN при запуске. Лицензии сторонних ресурсов — рядом с файлами и в THIRD_PARTY_NOTICES.md.

Светлая тема использует ту же композицию с белыми поверхностями и тёмно-зелёным акцентом. CSS-токены переключаются через html[data-theme]. Кнопка имеет доступное имя и сохраняет только предпочтение темы в localStorage под ключом vedomost-theme. theme.js применяет сохранённый выбор до загрузки основного скрипта; запрет доступа к storage не мешает работе. По умолчанию тема тёмная. Данные учеников и платежей в браузерное хранилище не записываются.

На телефоне навигация становится верхней панелью, таблица — карточками, форма переносится ниже. Есть фокус, подписи форм, статусы отправки, состояния ошибок и reduced-motion. Кнопки предыдущего/следующего месяца меняют тот же фильтр /debtors. Смена темы не меняет данные, месяц и заполненную форму.

Для UI UX Pro Max использовались общие рекомендации по доступности и плотности данных на раннем этапе. Финальное визуальное направление взято из Higgsfield, а не из автоматически предложенного маркетингового шаблона.
